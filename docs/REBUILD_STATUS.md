## 关键安全告警

旧的 `key.pem` 曾经公开提交。在重构分支删除它**不等于安全问题已经修复**；`main`、备份分支与 Git 历史可能仍保留这把私钥。

必须在服务器重新生成并切换全新的 TLS 私钥/证书，确认正在运行的服务不再使用旧私钥；再另行设计清理公开 Git 历史的方案（避免误删正常历史）。不要把新私钥传进聊天或 Git 仓库。
