# 《幻想乡》V5：只精修环境动态，不做手机布局/真人接入

**日期：2026-11-15。目标：直接沿用已认可的初代家园 2.5D 图像与交互点。**

## 本轮职责及禁止事项

- GPT 做：树叶内纹理微摆、地面叶影、落叶、烟囱烟、独立灯光、水纹、室内光束/浮尘、自然的昼夜渐变；Web 原型与 Godot 相互验证。
- **DeepSeek 做：Android 适配、捏合缩放、全屏浏览、触控布局与实际部署**，本轮 GPT 不碰缩放/布局。
- **不接 DeepSeek 或小冰等真实模型**，离线测试人偶保留但不新增居民权限、模型凭证、服务器写入或联网动作。
- 不画农田、不扩岛、不接连续地图、不降低原图质量、不修改服务端 V2 点位 ID。

## V5 动态具体实现与局限

1. **树冠内部真实像素微摆：** Godot 新增 `shaders/home_25d_wind.gdshader`，仅以遮罩作用于老树**树冠内部**，根据像素绿色通道和空间椭圆，采样原图的相邻像素，实现 1–2.35 px 横向风摆；HTML 用 `canvas.clip()` 加 `drawImage()` 从原始 1536×1024 PNG 的小裁剪区重取树叶纹理，避免“只画亮点当作树摇动”。树干、房屋、桌子、岛屿边界、居民落脚坐标完全不动。
2. **动态投影：** 在石桌附近和树下草地，用与树冠一致的慢速风频率更新低透明度叶影，避免明显的移动贴图。
3. **日夜渐变：** 约 **2.8 秒**从明亮白天过渡至紫蓝色黄昏，天空、屋内冷窗光与室外暖灯有各自的变化；旧 Godot 的瞬间 `modulate=#c4b5be` 已移除，Web 的整体亮度调低从 `.84` 收敛到 `.97`，色彩与区域灯光承担主体变化。`set_motion(false)` 冻结风、烟、落叶，但允许日夜过渡。
4. **细小动态：** 原烟囱位置产生分层灰白烟，落叶按不同速度/随机相位旋转飘移，左边海水安全区域产生独立反光线；黄昏出现低密度萤火点。
5. **室内**有暖灯闪动、黄昏偏蓝窗光、阳光斜射面、植物轻影和少量细小浮尘。
6. 默认**隐藏全部交互圈**，点击仍然可查看地点用途。

**不要误报：** 树冠外轮廓及大树枝干本轮仍未独立从整图拆出。V5 是树叶内部纹理局部形变 + 动态阴影，不是 3D 骨骼，也不具备居民被树冠遮挡的正式 Y-sort。小船仍静止，水面细波属于真实叠加动画。日夜真实灯窗 PNG 还没单独绘制发光贴图。

1. 从 GitHub 的 `prototype/ai-first-home` 分支获取 `prototypes/gpt_zero_home/25d_interactive/fantasia_first_home_25d_v5_dynamic.zip`；整个工程在独立 `/tmp` 解压，不覆盖 V3/V4、8080 或主工程。

4. Godot 4.6.3 导入：`godot --headless --path . --editor --import --quit`，运行 `res://tests/first_home_25d_smoke.gd`、`res://tests/ambient_godot_smoke.gd`、`res://tests/environment_v5_smoke.gd`，检查 shader import、`SCRIPT ERROR`、夜色过渡。
5. 浏览器预览运行后至少录制**10 秒的连续动态图**，必须看到可观察的树叶内部变化、飘叶、烟雾、柔光与水面；然后录制昼夜切换全过程。不能用静态截图证明动态。真机帧率、发热、性能由深寻验收。
6. 目前本地仅做 Node 逻辑/素材哈希及源审查；**Godot 运行需以 GitHub CI/深寻实机结果为准**。不可把源码检查直接当成手机验收。
