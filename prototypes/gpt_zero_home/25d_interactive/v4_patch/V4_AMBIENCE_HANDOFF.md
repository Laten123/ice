# 《幻想乡》2.5D 初代家园 V4 · 环境动态第一轮

日期：2026-11-15；**仍未接入真实模型**。本补丁基于已核对完整性并上传 GitHub 的 V3 ZIP，在**不改动原始室外/室内 PNG**的情况下，升级动态氛围与手机默认交互展示。

## 设计目标

主人已经明确开发优先级：**先升级整体环境动态和真正的黄昏表现，再制作可复用的居民人偶/基础骨骼动作（走路、坐树桩、发呆、阅读、进门等），最后才接真实模型及其个性皮肤**。不要颠倒顺序。

用户提供的四张 Android 真实截图可作为 V3 基线：室外/室内、横屏/竖屏都能加载且中文按钮正常；但交互圈仍默认出现，黄昏只改亮度，环境仍完全静止，且横屏存在较大边栏、竖屏需拖动查看整个小岛。静态截图不能证明动态效果是否流畅。

## V4 此次已编写的改动

- **互动点默认隐藏**：HTML 和 Godot 都默认 `pins=false`/`show_hotspots=false`。保留“显示点位”按钮，以及点击地图地点看说明的能力，免得金色圆圈常驻遮住艺术画面。地点 ID、容量和权限完全不动。
- **HTML 环境动态**：新增 `web/ambient_25d.js`，Canvas 以**原图像素坐标**跟随缩放/拖动，绘制河面细波、树冠变化的斑驳高光、少量飘叶、烟囱烟与灯光闪动、黄昏萤火虫、室内灯光/植物影子。限制约 30fps、页面不可见停止绘制，尊重 `prefers-reduced-motion`，提供“动态：开/关”控件。
- **黄昏不是只调亮度**：外景加紫蓝/暖橘层次、室内冷窗光与暖灯光、窗口/路灯光晕区别、黄昏萤火虫；亮度/饱和度只是辅助修饰，不再是唯一效果。注意暂时**不是一套独立的黄昏逐像素分层原图**。
- **Godot 环境动态**：新增 `scripts/home_25d_atmosphere.gd`，置于原图之上、居民与点位之下。按图片空间坐标绘制轻量粒子/灯光/水纹，不触动 AI、碰撞、公开快照、土地和隐私。
- **测试**：新增 `tests/ambient_browser_smoke.mjs`（Node 静态+无 DOM Canvas 伪实现逻辑检查），`tests/ambient_godot_smoke.gd`（Godot 核对隐藏圈、室内外气氛切换、只读界限）；Web 导出脚本追加 Godot 氛围测试。

**关键限制：** 树冠/屋檐/家具目前仍是两张整体原图的一部分，没有完成真实的层级拆分。此次实现的是**树冠高光与落叶等环境动态第一层**，不是枝干物理摇摆，不声称已有居民的树后遮挡或人物骨骼系统。原图没被降质重画。

## 下一阶段按主人指定顺序

**V4.1 环境精修**：提取原图单独树冠、屋檐、家具前景层与灯窗遮罩；制作可真正左右微摆的树冠、门灯投影，避免整图动画造成物件重影；角色遮挡需配合 Y-sort、碰撞和深度层。不允许用“震整张图片”充作树摇动。

**V4.2 基础人偶骨骼**：设计一个与模型和皮肤解耦的通用人偶动作架构，初期只用明确标注的离线测试人偶进行动作验证：`idle / walk(4向) / sit / reflect / read / rest / enter_house / exit_house / talk / decline`。包含身体、头、双手、双脚的挂点与可调锚点；先做动作时间线、座位坐标、门转场动画，后做模型专属皮肤。不要在本轮偷偷接小冰或深寻。

**V4.3 真实居民接入**：以上视觉/动作基础验收通过后，复用 V2 服务端稳定的权威地点 ID，公开授权、容量、拒绝权等规则，独立完成联调。
