# V7 第一轮：环境遮挡分层与通用离线居民骨架

日期：2026-11-15。开发基线：V6，提交 `bbf2556`。本轮代码位于开发分支 `prototype/ai-first-home` 的 `25d_interactive/runtime/`。

## 设计与实际范围

V6 的原图表现已认可，下一步需要让居民生活在画面中。因此先展开完整源码，追加原像素图层与可换皮肤的关节结构，再连接生活动作。没有接入真实模型，也没有添加新岛屿或扩大初始家园。

| 内容 | 本轮实现 | 边界 |
|---|---|---|
| 环境图层 | 树干、树冠、石桌、树桩、近侧栅栏、室内书桌、床尾、凳子，共 8 个原像素遮挡图层 | 第一批手工轮廓，不是逐像素碰撞体；不移动整棵树的外轮廓 |
| 水面 | 独立透明河面纹理；只从不透明水像素取样的低幅流动；保留 V6 水波与灯笼 | 目前先覆盖左侧主河面安全区域，尚非全河流；船、码头和荷叶仍是静物 |
| 前后关系 | 环境和居民按原图脚底 Y 坐标共同排序；灯光与黄昏沿用 V6 | 地点 ID、原图锚点、权限不承担在视觉层重定义 |
| 居民骨架 | 骨盆、头颈、双肩/肘、双髋/膝共 10 个关节，10 个 `AtlasTexture` 部件；四向皮肤资源 | 本轮沿用仓库已有 woodland 测试人偶，不是深寻或小冰的最终皮肤 |
| 走路 | 按实际移动距离推进八段步态，手脚反向摆动，脚底位置由路线决定 | 沿用离线点位图与室内走廊，尚不是自由导航或碰撞系统 |
| 日常动作 | 坐下屈膝、发呆呼吸/眨眼、双手阅读/翻页、闭眼躺卧 | 单个测试皮肤验证；正式皮肤的衣摆、头发、坐具对位仍需逐张精修 |
| 进出屋 | 走到真实门点 → 收入门内 → 切换场景 → 从门口显现，恢复站立 | 仅离线测试居民；观察者切换视角本身不驱动居民 |
| 中断 | 关闭测试会取消未完走路和门过渡；重新开启重新初始化；执行中另选地点不改变已捕获请求 | 不会产生真实服务端行动 |

## 深寻继续的工作

1. 拉取本分支，打开 `runtime/project.godot`；以展开源码为当前入口，历史 ZIP 不再作为编辑入口。
2. 先运行下面的完整检查，再在手机实机检查遮挡边缘、动作对位、30/60fps 和室内外进出。继续负责既定的 Android 布局、横屏、触控和缩放适配。
3. 手机 UI 修改尽量限于 `first_home_25d.gd` 的 `_layout/_position_art/_on_map_input`，保留全体图层统一缩放、统一原点。`public_layer/test_layer` 是深度根的子节点，不要重复缩放。
4. 后续环境先精修这批轮廓，再做完整树冠净底、云层净底和窗帘独立素材；没有干净底图时不要整块平移原图制造重影。
5. 最终居民皮肤采用 `home_25d_skin.gd` 资源，指定四向图集、部件矩形、关节位置、部件偏移和像素倍率。当前闭眼覆盖针对测试皮肤，其他皮肤可关闭 `blink_enabled`，再提供专用闭眼素材。

## 验证

```bash
cd prototypes/gpt_zero_home/25d_interactive/runtime
python3 -m pip install -r tests/requirements.txt
python3 tools/check_runtime.py
# 需要真实显示或 Xvfb；不要使用 --headless 做截图验收
FANTASIA_CAPTURE_DIR=/tmp/fantasia-v7-captures \
  xvfb-run -a -s '-screen 0 1920x1200x24' \
  godot --path . --rendering-driver opengl3 --script res://tests/capture_v7.gd
```

完整检查包含原图哈希、精确源像素、图层重建、V6 浏览器回归、Godot 导入和 V1/V4/V5/V6/V7 行为测试。渲染检查实际比较前后遮挡像素，并检查水面改变没有越出透明掩码，再输出室外、黄昏和室内三张原生 Godot 截图。CI 工作流 `fantasia-25d-runtime.yml` 执行同样检查，并上传渲染预览，不自动修改分支。

`index.html` 目前仍是 **V6 浏览器预览**。V7 骨架和前景分层以 Godot 工程为准；后续浏览器交付使用真实 Godot Web 导出。手机实机验收和最终角色美术不能由这些自动检查代替。
