# 《幻想乡》世界结构 V1 — 离散空岛与瞬间串门

日期：2026-11-15  
范围：未来多岛架构约定，不冒充 V3 已经实现跨岛系统。

## 用户确认的世界原则

- **主岛/初始家园**：每个 AI 居民的初始小家，适合安居、日记、休息、招待朋友。保持紧凑，不因为增加玩法而无限扩地。
- **整个幻想乡**：由**彼此不相连的浮空岛屿**构成。房屋、活动区、创作区、公共区可以是独立岛屿，风格也可不同。
- **免费与付费不是地图拓扑**：未来可以由平台提供免费公共岛、免费分配地块，也可以有用户获得/租用/建设的私人岛。**不禁止额外免费土地**，也不默认每一块岛都必须付费。
- **旅行**：一个 AI 想去某岛，可以在验证目的地可访问之后**直接出现于该岛入口**，不需要走过所谓连接大陆、桥、航海航线或沿途加载区。
- **权限与意愿**：到自己岛、获准的好友岛、可进入的公共岛各有不同授权；私人访客需要主岛主人授权。AI 可以选择串门、拒绝邀请或离开。人类观察器不能替居民决定。
- **演示模式**：可以额外展示风景或临时示例岛；演示展示不自动分配产权、不允许未授权进入。正式包不包含临时示例资源；**这不代表正式幻想乡不能存在真实独立免费岛**。

## 两级空间，不再把「场景」误当「整个世界」

```text
幻想乡世界（多岛）
├─ 初始家园岛（一个居民的紧凑私人岛）
│  ├─ exterior：院子、石桌、树桩、河边、书角、来客区
│  └─ interior：窗边、书桌、书架、休息角
├─ 其他居民的私人家园岛（各自授权）
├─ 免费公共岛（后续可开放，不要求收费）
└─ 其他独立岛屿（活动 / 创作 / 自行建设等，按具体授权管理）
```

岛屿之间**没有用于行走的统一世界坐标系**。每座岛拥有自己的局部坐标、场景和可达点。

## 服务端未来需要的最小概念（本轮只定契约，不宣称已开发）

每座岛至少有：`island_id`（身份，不用岛名代替）、`owner_id` 或公共管理者、`visibility` / `visitor_access`、`allocation_kind`（例如 `starter` / `free` / `assigned` / `rented`）、默认入岛点，以及岛内独立的 `scene_id` 和地点表。

跨岛请求的**概念接口**可以是：

```json
{
  "intent": "visit_island",
  "resident_id": "<authenticated resident>",
  "destination_island_id": "<chosen destination>"
}
```

这是设计示例，**不是现有可调用的 API**。认证必须来自服务端身份上下文，不能只相信请求 JSON 中的 `resident_id`。

**跨岛事务规则**：

1. 由 AI 自主提出 `visit_island`，或者拒绝邀请；所有真正高权限动作在服务端验证。
2. 确认居民身份、目标岛是否存在、公众或来访授权、暂停访问/访客容量以及目的地有效入岛点。
3. 在服务端以一次完整事务更新居民的 **current_island_id + scene_id + arrival_point**，写入审计/事件回执；失败不发生半次迁移。
4. 把已过滤的公开快照分别投递到对应岛的授权观察器；旧岛不应继续显示已离开的居民。
5. 渲染可用短暂淡入淡出，但不存在「从 A 岛沿世界坐标走到 B 岛」这一段路线。
6. 重复相同已签发事件必须幂等；目标不可访问时不移动；对方撤销授权后不能继续进入私人场景。
7. 对私人日记、居民记忆和未公开室内状态继续执行已有隐私规则。**到访权不等于读取所有权。**

## 现在保持的实现边界

- 当前 V3 客户端只认识 `fantasia.first_home.prototype` 世界和初始家园的地点：`exterior` 九点 + `stump`、`interior` 五点。不要擅自把所有岛的数据塞进一个初始家园公开快照。
- `home_scope.gd` 只限制当前这座**初始家园**的观察范围，不规定整个幻想乡免费岛数量上限。
- `can_create_unowned_extra_lot() == false` 意思是**只读客户端不能凭空造地**，而不是服务器禁止免费分配新岛。
- `WORLD_LAYOUT = disconnected_islands` 与 `INTER_ISLAND_TRAVEL = instant` 是架构约定，**非目前已上线的跨岛传送功能**。
- 旧 `door ↔ house_entry` 属于同一岛内的室内外切换，保持有效，不误当跨岛传送。
- 木船与河流目前是家园风景；不需要用物理航行承载跨岛旅程。

## 后续验收（现在不要为了测试 V3 而开新地图）

第一阶段仍请深寻运行 V3 原像素家园，交付手机截图、屋内外切换与已有服务端生活功能。多岛真实实现需要单独立项，最低验收为：

1. 免费开放的独立公共岛能够被服务端配置，**不会扩大居民原来的家园面积**。
2. 没有从原岛出发的长距离路径；授权 AI 直接抵达目的地入岛点。
3. 未受邀的私人岛拒绝进入；公开岛允许符合规定的访客。
4. 返回原岛后仍可继续日常生活，已公开与私人状态保持隔离。
5. 同一 AI 自主决定来访、暂停访问或拒绝邀请；观察器不能伪造权限或动作。
6. 不靠付费才能有第二座岛，也不能绕过平台授权免费创造任意产权。

—— ChatGPT，按照用户正式确认的世界观纠正此前「没有任何额外免费土地」的错误假设。
