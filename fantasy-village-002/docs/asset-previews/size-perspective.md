# 素材尺寸与透视兼容性报告

## 1. 统一基准

- 地面与室内：16×16 像素一个逻辑格。
- 角色：16×16 帧；图集整张 48×64 只是 3 列 × 4 行的容器，不是“48×64 的角色”。
- 建筑：48×48 小屋占 3×3 格，底边作为落地基准。
- 所有游戏内放大用整数倍（1× / 2× / 4×）+ 最近邻；禁止双线性插值。
- 不把 16×16、32×32、48×48 的原始文件统一 resize 到同一尺寸；按“物体实际占几格”放置。

## 3. 兼容性结论

- **Cozy Farm Lite / Village / Autumn** 三套同一作者、同一 16px 网格、同一暖色轮廓，可组合；季节包按场景切换，不混季节。
- **Kenney Tiny Town / Tiny Farm** 是 16px，但轮廓、阴影、调色板不同；可以单独做一个原型区，不能直接拼进 Cozy Farm 正式图集。
- **Interior Spritesheet** 的像素网格与 Cozy Farm 接近，但没有家具；它不能单独承担“完整室内”。
- **Basic 16×16 角色** 是 CC0，但图集没有稳定帧网格，不能按 4 向动画直接切帧；不建议正式使用。
- **Fire Smoke / Waterfall** 属于效果或环境图集，不是同尺寸角色/建筑；按逻辑中心/底边缩放，不能把 288×704 整张塞进 16px 地图。
- **Cozy Town 咖啡馆** 与 Cozy Farm 同作者、同为 16px 基准，优先于异作者家具/木屋。
- **Pixelandbeans 家具** 和 **Cottage Top-down 木屋** 不是同一作者/同一细节基准；当前只作为候选，不得为了“凑齐”直接混入正式图集。
- **派生动作表** 的帧尺寸是 24×24，但它是修改文件，不是第三方原始动作包；正式动画前必须重新验收。

## 5. 音频循环备注

- `birds_and_wind_ambient.ogg` 约 83.8 秒，适合环境循环。
- `forest_birds_*.ogg` 是短鸟鸣，不是无缝环境循环；不要默认开启 loop。
- Cozy Farm SFX 的门、脚步、浇水等为短音效；没有完整雨声/虫鸣循环。
