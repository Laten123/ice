## 审查结论

- 建筑和角色使用同一 16px 基准，可组合；不要把 16×16、32×32、48×48 直接按同一倍率硬放大后混用。
- 室内图集只有墙/地板，没有家具；不能据此宣称室内素材已完成。
- Basic 角色图集没有稳定帧网格，只作备选。
- 所有预览来自允许再分发的 CC0/CC-BY 素材；Cozy Farm 的 CC-BY 署名见上级 `ATTRIBUTION.md`。
