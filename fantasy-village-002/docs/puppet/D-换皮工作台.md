# D Resident Skin Studio

新增scripts/ui/resident_skin_studio.gd，直接实例化正式PuppetPlayer/Stage：皮肤、四方向、动作/设施选择，播放/暂停/重播、单次/循环、逐帧前后、速度、1/2/4/8倍最近邻、网格/关节/脚底/5px碰撞、透明棋盘/家园地面。预览可触摸滚动，竖屏上下布局，横屏左右布局，控制项触控高度44px，预览高度至少280px。不支持方向隐藏角色并明确提示，未实现动作不播放。

内置包只读；新建复制分层PNG并修改服装配色，保留原作署名；可编辑草稿名称/制作者，导入本地目录或ZIP、校验、导出标准包/图集/APNG/四方向PNG，应用通过路径信号传给家园。Web仅通过浏览器文件选择读取用户选择的ZIP，并通过download_buffer下载；不假设Android可读取任意目录。没有AI生图接口。

自动检查不替代人工美术和版权判断；导出需要工作台中的人工确认复选项。错误包不能导出。不修改皮肤的居民身份数据。

19/19工作台测试通过，包括360×800、480×800、844×390布局，暂停/逐帧、方向拒绝、真实新建/导出/干净重导入/应用信号。真实Godot截图previews/D-studio-landscape.png、D-studio-portrait.png、D-import-export.png。实际渲染发现滚动居中需等容器布局完成，已修复。字体仍为获准Noto CJK临时子集（OFL原文保留），补齐工作台文字。

本阶段工作台可独立运行；正式社区入口、持久外观绑定及家园生活见E。
