# B P0动作协议与设施

共享data/puppet/actions.json定义待机、眨眼、呼吸、行走、转身、坐下/坐姿/起身、拿书/开书/阅读/翻页/合书/收书、走近床/躺卧/睡眠/醒来/起床、开门/进屋/出屋/关门。P1舞蹈、P2种植明确未实现。每项动作声明支持方向、FPS、循环/单次、下一状态及部件关键帧，不把正面动作强套给背面。

运行时player.gd使用同一renderer.gd，支持播放/暂停/逐帧、速度、完成与中断复位。动作主要是整数关节关键帧、腿部90度像素折叠、表情替换和物品像素变化，不声称都是手绘全帧动画。未使用平滑旋转或模糊滤镜。held_anchors驱动书本，不随皮肤硬编码。

fixtures.gd从home_data.gd读取实际设施位置、接近点，统一椅前沿、床被面和门扇像素开合；stage.gd直接使用正式PuppetPlayer。关节/基线/碰撞调试由独立前景覆盖，避免关节被角色遮住。

两套皮肤对照previews/B-shared-fixtures.png为真实Godot渲染；472/472动作测试通过。moon可选头饰独立绑定head，睡眠修形由同一运行时renderer烘焙（tools/bake_skin_correctives.gd），无专属动作代码。初始头饰悬空问题已通过实际图像修正位置。

目前仅完成共享动作/设施运行基础，UI和正式家园入口在后续D/E接入。
