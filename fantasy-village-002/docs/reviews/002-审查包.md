## 2. 第一轮意见与修复对应

| 第一轮意见 | 本轮修改 |
| --- | --- |
| 强化 AppState 身份验证，补充非法绑定、重复模型 UUID、异常存档测试 | `_is_valid` 现在校验：账号/土地关联、绑定居民唯一且是社区列表中的同一对象、居民 UUID 唯一、模型 UUID 唯一且非空、模型标识与显示名非空、状态值合法。`load_identity` 拒绝坏 JSON、旧版本、缺失段、非法绑定、重复 UUID、绑定/社区模型不一致。新增 9 组负例测试。 |

| 修复材质切换后头像与世界角色外观不同步 | 材质切换同时更新顶部头像和地图角色；`BindingBar.refresh()` 不再重置头像颜色，在线/出门刷新后颜色保持一致；测试断言两者颜色相等。 |
| 检查横屏固定高度造成的地图挤压，逐步减少手写绝对坐标 | 横屏改为“左侧地图 + 右侧世界频道/底栏”，844×390 下地图高度从约 100 像素提升到 288 像素；布局尺寸集中为常量，未做大范围重写。测试新增“横屏地图不低于 240 像素”。 |
| 确保 002 正式源码能够从 GitHub 独立检出，而不仅是补丁文件 | 新增源码分支 `feature/002-community-ui`，包含完整 `fantasy-village-002/` 工程与 CI 配置；补丁只作为审查辅助。 |
