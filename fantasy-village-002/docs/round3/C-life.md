# 第三轮 C：独立区域与生活执行

将 HomePresentation 接入 HomePlot，移除旧整栋建筑/矩形房间的手工 _draw 拼接。保留身份构建、UUID、聊天/UI信号、A*代理、Action状态和Controller接口。新增实际 region，与 interior_visible 观察视图独立。两个区域各有边界、障碍和设施接近点；节点按脚底Y排序，被面与座椅前沿单独遮挡。主人仅能移动自己，通过门口路径进出；点击AI查看资料，点击设施保留说明。

模拟序列：室外阅读→入屋→书桌阅读→床铺休息→茶座→出屋→观察菜地。设施预订在寻路之前；占用、区域错误或不可达会释放/跳过并短暂退避，不强夺设施。移动与坐卧阶段分开，完成后归还预订。

帧动画：原角色6帧×四方向行走，项目派生待机闭眼、三帧屈膝坐下/反向起身、三帧开书/收书、四帧翻页、四帧抬杯、四帧头部呼吸。读书/喝茶的变化较细小。上下床及门口采用明确阶段的位置过渡、区域转移和被面遮挡，不声称具备完整手绘攀床、翻身、开门动作。床中只显示头部与原被面，是遮挡表现；休息并非完整人体睡眠动画。这些细节仍需视觉复审。

环境：13帧源水面循环、6帧派生烟团、4帧树冠像素摆动、4帧花局部变化；90秒加速本地日夜（初始白天），暖色窗灯/室内灯层，不修改UI颜色。无真实时间/AI服务。

访问权限独立小修：Registry绑定本地已认证主人/居民，拒绝仅传入他人UUID冒充申请/审批；同一pending申请幂等；已处理请求不能再次审批。保留原目标权限检查与公开字段白名单，无联网拜访。

Web实测发现导入后原始OTF/PNG会被Godot重映射；App字体和表现层支持导入资源加载，未导入源码运行保留原始读取。没有更换字体或皮肤。手机横屏实测发现800高基准画布会把整个UI缩得过小；改为响应式实际视窗尺寸，窄屏地图不足1倍时使用最近邻适配完整地块，足够空间仍取整数倍。

实际渲染发现负Z地面被外层Panel遮住，已提升表现根层级，专项测试增加回归。

代码位置：data/home_data.gd；scripts/world/{home_plot,home_presentation,resident_agent,mock_life_controller,plot_registry}.gd；scripts/app.gd。专项tests/home_v3_test.gd，原smoke_test更新了曾允许冒充邻居审批的错误预期。测试与真实图像见D记录。001及线上部署不变。
