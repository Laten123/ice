## 6. AI 自主生活演示

启动家园后不操作主人，`MockLifeController` 会驱动绑定 AI：

1. 选择长椅；
2. 寻路到长椅并坐下；
3. 停留后起身；
4. 走到小屋门并进入；
5. 在室内床铺休息；
6. 出门，继续下一个活动。

自动化测试在固定步长下验证 `sit / enter / rest / exit` 都出现，并验证主人点击地面只移动主人、点击 AI 只更新资料。

模拟控制器只是阶段 B 测试替身；未来真实模型实现同一个 `ResidentController` 接口，不改变场景、设施和动作系统。
