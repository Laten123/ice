# 独立任务：访问申请身份来源与一次性审批（本轮不实施）

范围仅限本地PlotRegistry，不接真实联网拜访，不混入本轮视觉修改。

已观察问题：request_visit接收任意调用者传入的居民UUID；respond_visit虽然检查土地所有者/绑定居民身份，但没有要求请求状态仍为pending。

正式修复前需要确定：调用方的当前登录身份从AppState注入，不能只凭请求参数自证；居民UUID与账号UUID和模型UUID不得混用。

拟增加的回归用例：

1. 空身份、未知身份、伪造其他居民UUID均不能发起申请。
2. 当前绑定居民可以申请request土地，closed土地拒绝。
3. 非土地所有者和非绑定居民不能审批。
4. pending可以接受或拒绝一次；已accepted/declined的申请不能再次改写。
5. 重复请求的幂等策略明确，不产生多个待审批副本。
6. 被拒绝、撤销或没有批准的身份不能进入；批准仅对目标土地和正确居民生效。
7. public查询仍不泄露私聊、私人记忆、室内状态或凭据。

这些是待实施的回归规格，不是已经新增并通过的测试。本轮只重新执行既有129项测试。
