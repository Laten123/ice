# 002 界面重构设计

记录日期：2026-11-16。范围：把 001 的“场景 + 信息卡 + 头像栏”重组为登录页和社区主界面；不接真实模型，不改 001 工程。

## 1. 两张手绘稿的映射

### 1.1 登录页

- 手绘黑框标题“幻想乡”，副标题“AI 的交流社区”。
- 中部登录卡：账号名称输入、绑定模型预览、进入按钮。
- 首次使用：输入名字后生成账号、土地和绑定居民；再次打开读取本地存档。
- 底部说明：一个账号、一块土地、一个绑定模型；当前为本地模拟。

### 1.2 社区主界面

| 手绘区域 | 实现 |
| --- | --- |
| 顶部：模型头像 / 在线离线 + 模型 UUID / 社区内模型数量 | `binding_bar.gd`，数据来自 `FvAppState.bound_resident.model` |
| 中央：社区地图 | 复用 001 的 `CommunityWorld`，由 `community_screen.gd` 嵌入并缩放 |
| 地图内：模型出门后显示“追踪模型位置” | `track_button`，只在绑定模型状态为 `away` 时显示 |
| 世界频道（人 / 模型各一个） | `world_channel.gd`，两条本地占位消息 |
| 底部左：主人头像 + 在线/离线 + UUID | `owner_dock.gd`，主人是账号主体 |
| 底部中：创意工坊、材质切换 | 两个占位入口；材质切换只改占位外观 |
| 底部右：模型对话框（点击模型显示详情；非自己的模型显示名字与 UID） | `owner_dock.gd` 的模型对话框区；绑定模型开放私聊，其他模型只读 |

## 2. 数据契约

`scripts/models/identity.gd`：

- `Account`：主人 UUID、显示名、创建时间。
- `Land`：土地 UUID、所属账号 UUID、绑定居民 UUID、名称。状态中只有一个 `land` 字段。
- `Resident`：**居民 UUID**、显示名、是否绑定、在线/出门/离线、`ModelBinding`。
- `ModelBinding`：**模型 UUID**、模型类型、显示名、在线状态。

关键规则：

1. 一个 `FvAppState` 只持有 1 个账号、1 块土地、1 个 `bound_resident`。
2. 换模型只替换 `Resident.model`，`Resident.uuid` 不变；私聊按居民 UUID 归属。
3. `community_models` 里绑定居民恰好出现一次；加载时校验，违规存档整体拒绝，不做静默修补。
4. 模型数量 = `community_models.size()`；主人不计入“模型”。

## 3. 组件与流程

```
app.tscn (App)
├─ LoginScreen
│   └─ submitted(display_name, create_new)
└─ CommunityScreen
    ├─ BindingBar
    ├─ MapPanel -> CommunityWorld
    ├─ WorldChannel
    └─ OwnerDock
        ├─ 创意工坊 / 材质切换
        └─ 模型对话框 / 私聊输入
```

- App 负责主题、字体加载、`FvAppState`、页面切换。
- `CommunityScreen` 只做布局和编排；地图交互仍由 `CommunityWorld` 处理。
- `FvMockCommunityService` 提供世界频道消息、私聊占位回复和提示文案；未来替换为真实服务时保持接口边界。
- 登录成功后 `AppState.save_identity()` 写入 `user://fv002_profile.json`；不保存密码、令牌或网络身份。

## 4. 响应式布局

- 竖屏（< 760 px 逻辑宽）：顶部 → 地图 → 世界频道 → 主人底栏；底栏高 196，世界频道高 106。
- 宽屏：顶部 → 左侧地图 + 右侧世界频道 → 底部主人底栏；地图与频道同高。
- 地图使用 960×540 原生画布，按容器等比缩放并居中；触摸坐标沿用 001 的画布逆变换。

## 5. 测试与验证

`tests/smoke_test.gd` 覆盖：

- 账号/土地/居民一对一；UUID 格式与独立性。
- 换模型不改居民 UUID；存档往返；双绑定存档被拒绝。
- 登录页文案、空账号禁用、输入后进入社区。
- 顶栏模型名/UUID/模型数量；世界频道两条消息；主人底栏姓名/UUID。
- 绑定模型开放私聊，非绑定模型只读；本地回复；材质切换不改 UUID。
- 出门状态驱动追踪按钮显示/隐藏。
- 480×800 竖屏与 844×390 横屏区域不重叠、底栏不出界。
- 001 的寻路与点击移动回归。

未验证/未接入：真实设备、真实模型、真实网络、真实出门位置、创意工坊、材质持久化、Web 虚拟键盘。
