## 3. 资源使用与范围约束

场景、人物、头像、地面和装饰全部由代码绘制，均为可替换的占位图形。没有下载或复制 itch、Kenney、rikaai、QQ 农场、旧工程或其他来源的美术素材。

Web 实测发现系统字体回退不提供中文字形。用户随后明确授权“允许添加临时中文 UI 字体”：使用运行环境自带 Noto Sans CJK SC 的 296 个字形生成 `assets/ui/placeholder_ui.otf`（84,524 字节），并重命名为 FV001 Placeholder UI。字体覆盖当前脚本和配置的全部可打印文字；SIL Open Font License 及来源见 `LICENSES/NOTO-CJK.txt`。`tools/make_placeholder_font.py` 可从已有系统字体重建子集，不进行字体下载。它是本阶段唯一额外授权的字体资源，不属于正式美术。

没有添加音乐、音效、真实 AI 接口、账号系统、联网聊天、数据库、存档、室内场景、物品经济、建造、养成、任务或其他复杂系统。居民自主散步和脚本对话只用于展示本阶段的基本交互。

`LICENSES/` 保存 Godot 引擎及其第三方声明，属于引擎运行时许可文件，不是美术资源。导出模板来自官方 Godot 4.6.3 Release，仅用于本项目构建。

## 5. 自动化测试与结果

测试脚本：`tests/smoke_test.gd`。完整控制台输出：`docs/test-results/001-smoke.txt`。

常规环境运行：

```sh
godot --headless --path . --script res://tests/smoke_test.gd
```

本次受限 Linux 工作区的默认用户数据目录不可写，因此使用可写的临时 XDG 目录运行，未修改系统目录权限：

```sh
mkdir -p /tmp/fantasy-village-godot-data /tmp/fantasy-village-godot-cache
XDG_DATA_HOME=/tmp/fantasy-village-godot-data \
XDG_CACHE_HOME=/tmp/fantasy-village-godot-cache \
godot --headless --path /workspace/fantasy-village-001 \
  --script res://tests/smoke_test.gd
```

最终该套测试结果为 **41/41 通过，退出码 0，控制台无 Godot 错误**。测试覆盖：

- 居民绕过建筑到达目标，整条路径保持在边界内且不进入阻挡范围；非法目标被拒绝，且不覆盖已有有效路径。
- 主人和两名 AI 的信息读取、选择信号、物品说明，以及检查物品时保留当前移动居民。
- 缩放和偏移后的触摸坐标转换，以及场景外点击不改变选择。
- 场景内点击空地后的主人移动、到达与停止。
- 约 30 秒逻辑时间内两名 AI 自主移动，以及至少两条定时占位对话。
- 入口场景、顶部社区名称、底部三个头像、头像选择与信息卡联动、问候台词更新和物品状态禁用问候。
- 通过 `Viewport.push_input` 分发真实输入事件，经过界面过滤后点击房屋、点击底部主人头像、点击地面启动移动，以及触摸场景居民。
- 480 × 800 逻辑视口下，信息卡中可见控件位于卡片范围内，并与底部头像栏保持分离。

测试中的“约 30 秒”通过固定步长推进逻辑时间，不需要真实等待 30 秒。无头输入测试验证事件分发链路，但不替代真实浏览器和实体设备试玩。

## 6. 开发中发现并修复的问题

| 问题 | 原因 | 修复和验证 |
| --- | --- | --- |
| AI 居民停留不动 | 居民空闲计时增加和场景倒计时减少相互抵消 | 统一由场景管理空闲倒计时；自动化确认两名 AI 在模拟期间自主改变位置 |
| 地图缩放后触摸或注入点击位置错误 | 直接使用未转换坐标或依赖实际鼠标位置，无法正确处理缩放、偏移及注入事件 | 鼠标和触摸事件均根据事件位置通过全局画布逆变换取得场景坐标；缩放触摸和实际视口事件测试通过 |
| 场景点击被界面遮挡 | 全屏根 `Control` 默认停止鼠标事件，导致场景的 `_unhandled_input` 收不到输入 | 根界面及地图承载控件使用忽略鼠标过滤，保留按钮正常交互；实际视口鼠标和触摸测试通过 |
| 小屏信息卡文字越界 | 紧凑卡片沿用大屏坐标，且对话标签的实际最小高度高于指定高度 | 调整紧凑布局的头像、说明、按钮与对话位置，紧凑模式隐藏辅助小标题；480 × 800 控件边界检查通过 |
| 受限环境启动 Godot 失败 | 默认用户数据和缓存目录不可写 | 测试使用临时 XDG 数据、缓存目录；构建工具为其运行隔离可写目录；未改变旧项目和系统目录权限 |
| Web 中文显示成方块 | Web 平台无法使用桌面系统中文字体 | 经用户明确授权加入临时 UI 字体子集，随后重新导出并检查桌面及移动端截图 |

## 8. 已知限制

- 角色和建筑是占位绘制，只有基础走路表现；建筑不可进入，长椅没有坐下行为，树木和告示牌仅可查看说明。
- 路径基于固定网格和静态物品阻挡范围，没有动态居民互相避让、复杂物理或动画状态系统。
- AI 对话为固定脚本，与真实模型、上下文记忆和网络服务无关；运行状态不保存，重新启动会恢复初始布局。
- Web 需要支持 WebGL 2 的浏览器及 HTTP(S) 服务；不能通过 `file://` 直接打开导出的 HTML 试玩。Android 局域网试玩需要手机与服务器处于可互通网络。
- 当前工作区为 Linux，无法把 Windows 导出或移动浏览器模拟描述成 Windows 原生或 Android 实体设备测试；最终验收应区分构建检查、浏览器模拟和真机测试。
- 本阶段不提供正式素材或音乐，也未提前实现后续里程碑。

### 浏览器测试复现

启动 `python tools/serve_web.py` 后，使用安装了 Playwright 的 Node.js 运行 `node tests/browser_smoke.cjs`。必要时设置 `NODE_PATH` 和 `CHROMIUM_BIN`。该依赖只用于开发测试，试玩无需安装 Node.js/Playwright。测试在三种视口中发送真实鼠标/触摸事件，通过信息卡像素变化确认房屋和头像点击生效，并保存截图及引擎控制台记录；中文显示另由截图人工检查确认。
